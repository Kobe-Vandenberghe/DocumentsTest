# Communication Guidelines

Northstar Digital expects communication to be clear, concise, and tailored to the audience. Internal updates should avoid unnecessary jargon, especially when they are shared across roles such as delivery, security, and operations. External client communication should reflect the same principles, but with extra care around commitments and implementation detail.

## Format expectations

- Use short summaries for routine updates.
- Highlight risks, blockers, and action items explicitly.
- Attach context when a decision affects scope, timeline, or budget.
- Preserve a record of approvals in shared project documents.

## Preferred channels

Teams should default to the shared workspace for project documents, the internal chat channel for quick coordination, and weekly project summaries for broader visibility. In urgent cases, the escalation path should follow the process in [Escalation Process](../clients/escalation-process.md) rather than informal side channels.

## Common mistakes to avoid

- Writing messages that sound final when the work is still uncertain.
- Leaving open questions in project threads without a clear owner.
- Repeating the same status update across multiple channels without adding context.
