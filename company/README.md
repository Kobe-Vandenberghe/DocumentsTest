# Company Knowledge Base Index

This folder contains the working knowledge base used by Northstar Digital for internal documentation and testing. It is intentionally structured so that people can find company strategy, operating practices, templates, and role-specific guidance without leaving the repository.

## Suggested reading paths

- New employees should start with [First Week](onboarding/first-week.md) and [Development Environment](onboarding/development-environment.md).
- Engineering teams should review [Development Process](engineering/development-process.md) and [Definition of Done](engineering/definition-of-done.md).
- Project managers can use [Project Delivery Process](projects/project-delivery-process.md) and [Project Kickoff Checklist](projects/project-kickoff-checklist.md).
- Sales and marketing teams can reference [Lead Qualification](sales/lead-qualification.md) and [How to Create a Press Release](marketing/how-to-create-a-press-release.md).

## Notes on usage

The collection includes a mix of active, in-review, outdated, archived, and draft documents. This makes it easier to test status filtering, overdue review detection, and document ownership views.
