# Client Communication Standards

Northstar Digital expects client communication to be timely, specific, and follow the agreed channel. A clear update is often more valuable than a long explanation, especially when the client is trying to understand the current state of a project.

## Standards

- Send updates on the agreed cadence unless there is a reason to change it.
- State the current status, the next milestone, and any relevant blockers.
- Use plain language, especially when the update includes technical or operational detail.
- Record decisions and follow-up actions in a shared project document.

## Examples

For a project such as the Fleet Operations Portal for Greenline Logistics, a status note should highlight whether the latest sprint was completed, what remains for the next milestone, and whether any scope questions need client input. For BrightPath Health, communication tends to need extra care around confidentiality and the timing of changes that affect operational users.
