# Security Training

All employees are expected to complete the basic security training during onboarding, regardless of role. The goal is not to turn every employee into a security specialist, but to ensure that everyone understands the risks associated with client data, access control, and everyday digital habits.

## Core topics

- Password hygiene and MFA use
- Safe handling of client data and shared credentials
- Recognition of phishing and social engineering attempts
- Appropriate use of AI tools and public chat systems with client data
- Reporting incidents quickly rather than trying to resolve them alone

## Practical reminders

Employees should not store sensitive client material in personal email or unapproved cloud storage. If a project includes a temporary environment that is still under review, that environment should not be shared outside the approved team. If in doubt, ask the security team before acting.

## Review cycle

The training should be revisited annually and after any material security incident. The current content references the older approval process for temporary access requests, but the newer expectations are described in [Password and Access Policy](../security/password-and-access-policy.md).
