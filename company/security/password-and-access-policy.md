# Password and Access Policy

Northstar Digital requires strong identity management practices to reduce unauthorized access and to protect client systems. All users must use company-approved authentication methods and follow the minimum security controls required for their role.

## Minimum standards

- Use a password manager and unique passwords for each service.
- Enable MFA for all business accounts where available.
- Keep access proportional to the role and project need.
- Request changes to access promptly when responsibilities change.

## Access management

Managers should approve access requests before the security team completes the setup. Temporary access for short-term projects should be reviewed regularly and revoked promptly once the need ends. In some situations, the recorded approval can be a ticket, email thread, or workspace note, as long as the decision is easy to trace later.

## Exceptions

Exceptions should be rare and documented. If a project needs a shared account or a bypass to an internal control, the request should be reviewed by the security officer and the project lead. No exception should be kept undocumented for long.
